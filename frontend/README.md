# Frontend

The React/Vite client for Japan Travel Planner. The repository-level [README](../README.md) contains complete setup, testing, architecture, and deployment instructions.

For local development, copy `.env.example` to `.env` and run `npm install` followed by `npm run dev`. The local environment points API requests to Spring Boot on port 8080; production uses same-origin requests from the bundled Spring Boot application.

Use `npm run lint`, `npm test`, and `npm run build` before submitting frontend changes.
